# #098 — chain-wide DoS/capture/privacy hardening, accessible liveness fallback, accountability-council reverse-overlap gate (2026-08-28)

Three same-day/next-day commits, not previously given their own changelog entry (they were only
referenced indirectly, if at all, elsewhere). This entry records what each actually did.

## What changed

**`4515618` — close DoS, capture, and privacy gaps across the runtime pallets.** Fixes from an
independent five-lens review plus a follow-up multi-agent code review, spanning nine pallets:

- **pallet-treasury-ledger**: reject zero-amount expenditures (closed a free unbounded
  storage-growth DoS reachable via a compromised department-spender key).
- **pallet-anticorruption**: price `submit_whistleblower_report`'s ZK verification weight
  realistically instead of a flat placeholder; add `reject_report_action` so a stuck
  Clear/ReferToCourts proposal can be unstuck without waiting on the original proposer;
  auto-clear a removed investigator's pending proposals; price `remove_investigator`'s unbounded
  `PendingReportAction` scan.
- **pallet-courts**: dedupe `LawChallenge` cases per law; exclude the case filer (and, for
  `CitizenConduct`, the defendant) from jury selection, and make `select_jury`'s eligibility
  check account for that exclusion instead of stranding cases when the pool is exactly at the
  required size; add `CaseSubject::TierConflict` plus a permissionless `challenge_law_tier` path
  (via `pallet-constitution`) so constitutional content can't be enacted at the Ordinary tier to
  dodge entrenchment and mandatory AI review; anonymize filing for
  `LawChallenge`/`TreasuryDispute`/`TierConflict` via a ZK nullifier instead of a public
  `AccountId`, decoupling the filing bond from the (possibly anonymized) stored filer; unify the
  `LawChallenge`/`TierConflict` duplicate-case guards into one map keyed on `law_id` alone
  (keying on `(kind, law_id)` didn't actually prevent the two case kinds colliding against the
  same law); harden the bond-release path with a debug assertion against a future
  storage-invariant violation; price `remove_oracle_member`'s unbounded re-resolution loop
  realistically.
- **pallet-elections**: bound `run_election`'s delegate scan across blocks via a cursor instead
  of one unbounded per-block iteration; require ZKPassport proofs presented to
  `register_as_delegate` to carry this service's own scope/subscope tag; require sustained
  backing before it counts toward a legislature seat, closing a flash-backing window at the
  election snapshot.
- **pallet-executive / pallet-emergency-council**: reject a `vote_declare_emergency` call whose
  terms don't match the already-pending proposal instead of silently discarding them (closes a
  front-running path in both twin mechanisms); cross-wire each pallet's cooldown so declaring via
  one mechanism also gates the other, closing a back-to-back-emergency loophole neither pallet's
  own cooldown covered alone.
- **pallet-identity**: require ZKPassport proofs to carry this service's own, per-call
  scope/subscope tag (registration, reverification, recovery, and OPRF-scheme migration each get
  a distinct subscope, so a proof for one can't be replayed into another).
- **pallet-voting**: allow overwriting an already-cast vote commitment before a referendum's
  window closes, giving a coerced citizen a way to silently override a forced vote (on-chain
  override only — the privacy-preserving tally still depends on the not-yet-built off-chain MACI
  coordinator); close a delegation race in the window between a referendum's close and its
  finalization.

**`261941e` — accessible liveness fallback, security/privacy fixes, and courts sync (mobile).**

- Adds a QR-code liveness alternative for citizens who can't perform facial articulation
  (blink/turn): the QR nonce and the face-match photo are captured in the same frame, twice in
  sequence with a fresh nonce each time (`qrLivenessChallenge.ts`, `qrCodeMatrix.ts`, native
  `QrChallengeModule.kt`), so a static photo alone can no longer pass either liveness path. Fixes
  the native capture callbacks' main-thread-blocking `Tasks.await()` call along the way, which
  had made QR decoding fail unconditionally.
- Adds best-effort Android Play Integrity attestation captured alongside registration
  (`playIntegrity.ts`, `PlayIntegrityModule.kt`, via `deviceIntegrity.ts`) — client-side signal
  capture only (verifying it needs a standalone service this doesn't build); run in parallel with
  the liveness UI rather than blocking the screen on it, with a timeout.
- Syncs `mobile/src/chain/courts.ts` to `4515618`'s pallet-courts rework: `file_case`'s new proof
  arguments, the new `TierConflict` case type, and the new anonymized-vs-plain filer
  representation — case filing and the case list were both broken against the new chain shape.
  Disables the three proof-required case types in the filing UI rather than offer a picker
  guaranteed to fail on submission, since no on-device prover exists yet to generate their
  proofs.
- Fixes an expired-passport date picker silently refusing to accept a real (past) expiry date;
  adds upfront registration/recovery warnings before a citizen invests time in a flow that can't
  complete yet; adds passport/country eligibility disclosure; moves locally-cached registration
  progress off persistent storage and adds a citizen-triggered way to clear it.
- Reverts a de-emphasized text style on the desktop-auth confirmation screen that had landed at
  the same time its copy started asking the user to scrutinize that exact text for phishing; fixes
  a silently-swallowed error in the registration-status "clear" action.
- Rewrites engineering jargon in citizen-facing copy; wires a react-i18next foundation (English
  content only) across a first set of screens.

**`ab04b13` — close reverse-direction legislature/executive overlap gate.**
`pallet-accountability-council`'s `add_member` already blocked a sitting legislature/executive
member from joining the Council, but nothing stopped the reverse: a Council member could later be
seated by `pallet-elections`' automatic top-N seating or appointed a minister/PM by
`pallet-executive`. Implements the already-wired `AccountabilityCouncilChecker` trait
(consumer-defines/provider-implements, mirroring `DisclosureChecker`) on
`pallet-accountability-council`'s own `Pallet<T>`, closing the gap on both directions. Also
refreshed `next-steps.md`, `architecture.md`, `docs/project/pallets/accountability-council.md`,
`docs/project/pallets/voting.md`, `docs/project/README.md`, `court-oracle/README.md`, and
`docs/project/apps/mobile.md`'s mobile test counts to match already-landed commits.
